# 투수 없는 야구: 티볼 2차시 수업 제작 리서치

중2 티볼 수업의 판정 규칙은 대구광역시티볼협회 누리집에 게시된 「티볼규칙(2014년 제정)」만으로 거의 다 정할 수 있었습니다. 핵심은 다섯 가지입니다. 첫째, **2스트라이크 뒤에는 헛스윙·티 치기·파울·번트·10초 초과 중 하나만 더 해도 타자 아웃**입니다(파울도 아웃이라는 점이 야구와 다릅니다). 둘째, **파울라인은 페어**이고 내야는 멈춘 곳, 외야는 처음 떨어진 곳으로 판정하며, **타자 서클(반지름 3 m) 안에 멈춘 공은 파울**입니다. 셋째, 주자는 **타자가 친 뒤에만** 베이스를 떠날 수 있고(루반칙), 슬라이딩은 아웃입니다. 넷째, 2017년 개정으로 **홈은 언제나 포스아웃**입니다. 다섯째, 공수 교대는 **전원 타격제 + 잔루 인정제**가 기본입니다. 근거 원문: `docs/research_notes/teeball/rules_daegu_2014.md`.
