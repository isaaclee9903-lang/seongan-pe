## 핵심 질문 4: 임베드·기술 메모(수업 페이지 제작용)

### Takeaway
후보 영상은 모두 임베드가 허용된다. 그런데 `https://www.youtube.com/embed/ID`를 Referer 없이 최상위로 열었을 때 **"동영상 플레이어 구성 오류 – 오류 153"**이 났다. 수업 페이지는 반드시 http(s)로 배포하고(file://로 열지 말 것), Referer를 보내야 한다.

### Cited Findings
- 2026-10-08 내장 브라우저에서 `https://www.youtube.com/embed/RVXjQ4EzXKE`를 직접 열었더니 화면에 "동영상 플레이어 구성 오류 / 오류 153"이 표시됐다(직접 관찰). 같은 영상은 watch 페이지에서 정상 재생되고 `playableInEmbed=true`였다 — [영상](https://www.youtube.com/watch?v=RVXjQ4EzXKE)

### Inferences
- 오류 153은 임베드 요청에 Referer(출처)가 없을 때 나는 것으로 보인다. iframe에 `referrerpolicy="strict-origin-when-cross-origin"`을 두고(`no-referrer` 금지), IFrame Player API를 쓸 때는 `origin` 매개변수에 배포 도메인(예: GitHub Pages)을 넣고, `start`/`end`와 `getCurrentTime()` 폴링으로 퀴즈 정지 시점을 구현하는 것을 권장한다. 반드시 배포 URL에서 실제 재생을 시험해 볼 것.
- 광고: watch 페이지 재생 시 광고(6초·30초)가 붙었다. 임베드에도 광고가 붙을 수 있으므로, 퀴즈 타이밍은 영상 시간(`getCurrentTime`) 기준으로 잡아야 한다.

### Gaps
- 오류 153이 정상 Referer가 있는 배포 페이지에서는 사라지는지는 이 환경에서 시험하지 못했다(로컬 서버를 내장 브라우저로 열 수 없음).
