# 중2 체육 · 영역형 스포츠 · 태그럭비 (기준 문서 초안)

> 교과서를 받지 않고 리서치로 만든 **초안**이다. 선생님이 교과서·수업 규칙과 대조한 뒤 확정한다.
> 근거: `docs/태그럭비 수업 제작 리서치.md`, `docs/research_notes/tag-rugby/`

## 1. 교육과정 위치 (2022 개정, 교육부 고시 제2022-33호 [별책 11])
- 영역: 스포츠 → 전략형 → **영역형 스포츠** (2015 개정의 '경쟁 영역'이라는 이름은 쓰지 않는다)
- [9체02-10] 영역형 스포츠의 역사와 특성을 탐색하고 비교한다. → 05 경기장 밖 이야기, 영상 1(유래)
- [9체02-11] 영역형 스포츠의 수행 원리를 적용하여 경기 기능을 수행하고 향상한다. → 03 규칙 놀이터
- [9체02-12] 영역형 스포츠의 경기 방법을 이해하고 경기 전략을 활용하며 안전하게 경기한다. → 02 규칙 읽기, 04 내가 심판
- [9체02-26] (태도) 신뢰, 팀 목표, 경기 예절, 정정당당한 참여 → 태그 외치기·돌려주기, 정직한 판정

## 2. 이 자료의 기본 규칙 (대한럭비협회 영상 + RFU 학교 규칙 절충)
| 항목 | 이 자료의 값 | 다른 값 | 근거 |
|---|---|---|---|
| 인원 | 5~6명 | 4~7명 | 협회 제3강, RFU |
| 태그 | 양쪽 골반에 1개씩 2개, 1개만 떼도 태그 | | 협회 제1강, RFU |
| 태그 콜 | 수비가 태그를 들고 "태그!" | | 협회 제2강 |
| 태그 뒤 공격 | 3걸음 안에 멈추고 3초 안에 옆·뒤로 패스 | "즉시 패스" | RFU 6e, 인천 영상 |
| 태그 뒤 수비 | 3m 물러남, 패스 후 태그 반환 | 1m(RFU 태거), 5m | 협회 제2강 |
| 공수교대 | 5번째 태그 | 3번, 6번 | 협회 제3강(3/5), 인천 영상(5) |
| 프리패스 | 반칙 지점, 수비 5m | 7m(RFU) | 국내 영상 |
| 녹온 | 앞으로 놓치면 상대 공, 옆·뒤는 경기 계속 | 애니메이션은 "떨어뜨리면 교대" | 협회 제2강 |
| 득점 | 인골에 손으로 공을 내려놓으면 1점(정규 15인제는 5점) | | 협회 애니메이션, 인천 영상 |
| 금지 | 접촉, 핸드오프, 태그 가리기, 옷 잡기, 다이빙·슬라이딩, 공 차기 | | 협회 제2·3강, RFU 9 |

## 3. 다른 교과 연결 (과학, 2022 개정 [별책 9])
- 사용: 힘의 표현·탄성력([9과05]), 기체의 압력과 입자 운동([9과06]), 운동(빠르기, [9과19])
- 정성적으로만: 자이로 효과, 마그누스 효과, 상대 속도·기준틀(용어 쓰지 않음), 반발 계수, 토크
- 쓰지 않음: 스핀 패스 거리 증가 수치(근거 없음), 린던 고무 튜브 연도(자료마다 다름)
